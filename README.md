### /replay

Replay is a command to save replays for your memories. The /replay command has 4 different moves:
| Argument List | About this argument |
| -------- | -------- |
| `/replay play <filename>` | Lets you play your recordings with file name. (Must be on freeplay mode or new name Practice mode) |
| `/replay stop ` | Lets you stop the recording thats playing. |
| `/replay record <filename>` | Records your replay file on `C:\XboxGames\Among Us\Content\replays`. |
| `/replay stoprecording` | Lets you stop recording a replay. |

When you start playing a replay, you are a ghost. And you start chatting yourself in the chat, the reason of this is the replay. Its to implement who killed who, who called a meeting, who chatted and more.

> [!IMPORTANT]
> Please use the second mod we gave in the release named "AmongUsChatUnlocked.dll" to unlock the chat in practice mode to play replays.

Includes you have commands when you are playing a replay.



| Replay Command List | About this argument |
| -------- | -------- |
| `/pause` | Pauses the replay. |
| `/resume` | Resumes the replay. |
| `/length` | Shows you the length of the replay. |
| `/time` | Changes where to play of the replay. |
| `/haunt <username>` | Haunts someone with username. |
| `/roles` | Shows everybodys roles in the exact second of the replay. |
| `/role <username>` | Shows 1 persons role. |
| `/spectate` | Something similar to /haunt. |

> [!CAUTION]
> Dont forget to run the replay on practice mode, below the Online button!

### /kick
Kicks somebody from the game as host.

### /forcestart
Force starts a game. Working on it.

### /forceskip
Forcefully skips a meeting. Working on it.

### /setting
Use: /setting \<setting> \<value>

To change settings easier.
### /map
Use: /map \<map>

To change the map without closing the chat.

### /custompreset
Use: /custompreset \<one of these options below>

### custompreset/HardMode
Makes the game harder for crewmates!

### custompreset/BeginnerMode
For beginners.

More presets are coming soon.
